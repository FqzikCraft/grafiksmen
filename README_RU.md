# КутиКатай — график смен

Адаптивное приложение с тёмной темой для Vercel Functions и PostgreSQL в Neon. Интерфейс администратора и страница сотрудников работают с общей базой данных.

> **Важно о бесплатном тарифе:** Vercel Hobby бесплатный, но предназначен только для личных некоммерческих проектов. Для рабочего приложения компании понадобится Vercel Pro или другой хостинг, условия которого разрешают коммерческое использование. Neon предлагает план от $0, но проверьте актуальные лимиты и условия перед публикацией.

## Что входит

- Вход администратора по секретному паролю.
- Настраиваемый список сотрудников и катков.
- Ссылка самостоятельной регистрации сотрудников. Форма собирает имя, фамилию и Telegram ID.
- Отдельная персональная ссылка для доступности каждого сотрудника.
- Доступность по каждому дню недели с собственным временем начала и окончания.
- Настройки «открыто/закрыто», часов работы и необходимого числа сотрудников для каждой точки и даты.
- Создание и редактирование смен с произвольными часами и быстрыми шаблонами 10:00–16:00, 16:00–22:00, 10:00–22:00.
- Подбор черновика: заполняет получасовые интервалы по доступности сотрудников, часам точки и требуемому количеству людей; недостающие интервалы показывает перед сохранением.
- Проверка пересечений смен одного сотрудника и соблюдения часов работы точки.
- Экспорт графика в CSV.
- Сохранение данных в PostgreSQL. Схема таблиц создаётся приложением при первом обращении к API.

## Развёртывание на Vercel

### 1. Создайте базу данных

В Vercel откройте **Integrations → Marketplace → Neon**, создайте базу данных на подходящем плане и подключите её к проекту. Скопируйте Postgres connection string.

### 2. Загрузите папку проекта в GitHub

Загрузите содержимое этой папки в новый GitHub-репозиторий. При импорте в Vercel выберите именно папку `kutikatay-vercel`, если добавляете её в существующий репозиторий.

### 3. Добавьте секреты

В Vercel откройте **Project → Settings → Environment Variables** и задайте для Production и Preview:

| Переменная | Значение |
| --- | --- |
| `DATABASE_URL` | строка подключения Neon (Postgres) |
| `ADMIN_PASSWORD` | длинный уникальный пароль администратора |
| `SESSION_SECRET` | случайная строка не короче 32 символов |

Не добавляйте реальные пароли и строки подключения в GitHub. Пример локальных переменных есть в `.env.example`.

### 4. Запустите публикацию

Импортируйте GitHub-репозиторий в Vercel и нажмите **Deploy**. Для этого проекта не нужна команда сборки: Vercel обслуживает файлы из `public/` и API-функции из `api/`. После добавления переменных повторно запустите Deploy.

Откройте сайт и войдите с `ADMIN_PASSWORD`. При первом обращении приложение создаст таблицы в базе.

### 5. Добавьте точки и сотрудников

В панели откройте **Точки**, добавьте катки, задайте для каждого дня часы работы и нужное число сотрудников. Затем откройте **Сотрудники → Ссылка регистрации** и отправьте ссылку команде. Сотрудник регистрируется по ней, затем попадает на страницу своей доступности. Персональную ссылку сотрудника можно скопировать из его строки в списке.

## Локальная настройка

Скопируйте `.env.example` в `.env.local`, укажите настоящие значения переменных и установите зависимости командой `npm install`. Для запуска Vercel Functions локально используйте Vercel CLI: `vercel dev`.

## Поведение ссылок

- Ссылка регистрации позволяет зарегистрировать несколько сотрудников и остаётся активной, пока администратор не нажмёт **Отключить старые ссылки**.
- Персональная ссылка открывает только форму доступности конкретного сотрудника. Если администратор выпустит новую ссылку для сотрудника, старая перестанет работать.
- Telegram ID хранится в базе как введённый числовой идентификатор; интеграция с Telegram-ботом и автоматическая отправка сообщений в этот прототип не включены.

## Ограничения первой версии

- Подбор черновика использует доступность на выбранные дни и старается распределять часы между сотрудниками; администратор проверяет и редактирует результат.
- Требуемое число людей на точке задаётся на день. Подбор закрывает временные интервалы по 30 минут и может оставить пробелы, если доступных сотрудников не хватает.
- В первой версии одна компания использует одну базу и один пароль администратора. Перед публичным запуском смените пароль на длинный уникальный и храните секреты только в настройках Vercel.
